# Frontier Game 

## Objective
To learn about the use of redux toolkit in the setup of a redux app. Also, re-factor the Redux_Road.js exercise that was used to learn Flow. Finally, generate a friendly UI.

## Technologies Used
- Vite
- React
- Redux
- HTML, CSS
- JavaScript
- node.js
- Copilot

## How to play
To start the game:
* Run npm run preview to start the production version locally.

Gameplay:
* Move your cart forward by making sure that you have enough supplies. If you run out, your cart will not move! 
* You can gather or buy supplies. 
* If you get robbed, you can sell some of your supplies to recover some cash. You can use your cash to buy supplies to continue your journey. 
* The story you unfold is described on the right side of the UI. Enjoy your journey!
